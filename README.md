# python-hangman-game
A simple Hangman Game developed using Python. The game randomly selects a fruit name, and players have limited chances to guess the correct word letter by letter.

Python Hangman Game

Project Overview

The Python Hangman Game is a simple word-guessing game developed using Python. In this game, the computer randomly selects a fruit name from a predefined list, and the player has to guess the word by entering one letter at a time within a limited number of chances.

This project demonstrates basic Python programming concepts and logical thinking through an interactive game.

 Objective

To develop an interactive Hangman game using Python that helps understand programming fundamentals, conditional statements, loops, lists, and random word selection.

Tools & Technologies Used

- Programming Language: Python
- Platform: Google Colab
- Module: Random

Project Features

- Random selection of fruit names.
- Letter-by-letter word guessing.
- Limited chances to guess the correct word.
- Displays correctly guessed letters in their respective positions.
- Prevents repeated guesses of the same letter.
- Displays remaining chances after an incorrect guess.
- Shows a winning or game-over message.

How the Game Works

1. The computer randomly selects a fruit name from a predefined list.
2. The player sees blank spaces representing the letters of the selected word.
3. The player enters one letter at a time.
4. If the guessed letter is correct, it appears in the corresponding position.
5. If the guessed letter is incorrect, one chance is deducted.
6. The player cannot guess the same letter twice.
7. The game continues until the player guesses the complete word or runs out of chances.

Note: The player gets chances equal to the length of the selected word plus 2.
